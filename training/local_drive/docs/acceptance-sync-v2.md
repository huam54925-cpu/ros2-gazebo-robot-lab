# 固定场景同步后端 v2 本地验收

2026-10-12，在本地 GTX 1650 / Docker 29.1.3 上执行。RTX 4060 目标机无网络、无 SSH，本轮没有连接该机；目标基线见 [WSL2记录](acceptance-wsl2-rtx4060.md)。实现与边界见 [同步后端](sync_backend.md)。

## 通过的检查

- 20项训练/环境单元测试与4项原生传输边界测试通过。
- 原生transport独立请求进程连续80步通过；每步0.2秒、200个1ms物理步，动作应用回执和lidar/odom/truth严格目标时间验证保持1e-6秒容差。
- 三次同seed冷reset、相同动作序列，时间、odom和真值轨迹差异为0，激光通过1e-6重复容差。
- SB3与Gymnasium环境检查通过；三回合随机采集36条转换通过历史与观测审计。
- ACK缺失、旧激光、跨回合数据均抛InfrastructureError，实际SAC回放保持2→2、4→4、6→6；停车故障不遮盖原始ACK错误，销毁后重建成功。
- 最终镜像不挂源码运行CUDA短验收：64步、48次梯度更新、actor最大参数变化0.007888644933700562；模型和回放重载后继续8步，最终回放72条。6个检查点SHA256均通过。
- 以上最终复测使用Mesa llvmpipe EGL仿真、CUDA学习器，与目标4060文档中的分工一致。不是NVIDIA图形渲染验收。

初期逐次CLI请求曾出现空状态响应和world control响应超时，失败日志与16/32步检查点保留在离线包证据中，未作为成功结果。最终改为独立持久原生请求进程；动作与推进不自动重发，只读状态最多3次重试。随后整套门禁和最终镜像训练重新通过。

## 使用

开发时挂源码验证，稳定后执行 `scripts/build_sync.sh`，使用已经缓存的仿真/CUDA基础镜像构建两个派生镜像，无须重新安装依赖。镜像在本地通过 `docker save` 导出，镜像、训练权重和大体积验收数据不上传GitHub。

离线包包含run-offline.sh、SHA256SUMS、两张镜像的tar.gz、源代码快照、依赖锁、镜像ID、源码哈希和本地验收证据。整个目录拷贝到目标WSL2 Linux文件系统后执行 `bash run-offline.sh`。脚本源码为 `scripts/run_offline.sh`，需要放在导出文件旁执行。一次性门禁失败即停；4060结果必须由该机实际运行生成。

`training.train_vehicle` 已独立于验收脚本；`--profile acceptance/formal` 区分参数，正式learning_starts=5000。当前尚未实现日常训练的自动基础设施故障续训，两种profile均上抛错误并清理。后续恢复需在学习器采样边界丢弃坏转换并开启新回合，不能将后台reset伪装成成功step。短训练不代表导航收敛。
