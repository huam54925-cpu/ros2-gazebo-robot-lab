## 观测、动作和奖励

295维观测由激光270维、odom速度2维、目标相对距离/方向3维及4帧动作与odom位移历史20维组成。历史由旧到新、reset清零；目标方向用sin/cos表示。真值只能用于奖励、终止判定和评价，不能拼入策略输入。具体归一化、坐标系及无效激光处理以接口说明为准。

动作a属于[-1,1]^2：v=0.2+0.4*a0，w=0.8*a1。允许[-0.2,0.6]m/s前后运动及[-0.8,0.8]rad/s转向。动作[0,0]会前进，停车必须调用独立stop接口。

每步推进0.2仿真秒，回合上限600步。初始奖励为：

```text
r = 2*(d_before-d_after) - 0.05*dt - 0.2*stalled
    - 0.01*sum((a-a_previous)^2) + 10*arrival
```

距离使用驱动轮轴心到目标的真值距离。arrival仅在首次进入0.35m到达半径的终止步计一次；若reset时已在目标内，应重采初态，不能收集零长度成功回合。stalled使用最近2仿真秒的轨迹窗口，窗口未满时不处罚；满窗口路径<0.05m且平均请求速度绝对值>0.05m/s时为真。所有窗口必须在reset时清空。

没有接触传感器时，contact标记unknown、碰撞奖励权重0，不能把激光距离当作接触事件。翻倒终止阈值仍需仿真实测定版。奖励系数是待调设计值，不代表训练效果。

## SAC更新与回放

使用两个Q网络及其目标网络、带tanh压缩的随机策略和自动熵系数。网络隐藏层[128,128]，学习率3e-4，gamma=0.99，tau=0.005，batch=256。先收集5000条有效transition，再按每个环境步一次梯度更新，Replay Buffer容量200000。短测入口临时使用[32,32]和更小buffer，不可将短测结果当此车辆配置的训练结果。

设计上的一步目标与策略损失为：

```text
a_next ~ policy(obs_next)
y = reward + gamma * (1 - terminated) *
    (min(Q1_target(obs_next,a_next), Q2_target(obs_next,a_next))
     - alpha*log_prob(a_next))
L_actor = mean(alpha*log_prob(a) - min(Q1(obs,a), Q2(obs,a)))
```

时间上限作为外部截断，使用真实末帧继续bootstrap；不能拿自动reset后的首帧充当末帧。目标到达或有效终止事件不bootstrap。SB3的VecEnv包装层需要保留terminal_observation和超时信息；适配器验收必须覆盖这一点。墙钟超时、旧帧、回合串扰或缺少动作应用ACK是基础设施错误，不进入回放，也不伪装成终止。

## 后续实现顺序

```text
冷reset，得到本回合有效首帧，清空历史和奖励窗口
循环：
  采样动作 -> 解码物理速度
  仿真插件确认动作已应用 -> 精确推进200ms -> 收齐目标时刻的帧
  校验回合/动作编号/时间/字段 -> 拼接obs -> 计算奖励和终止标志
  只将完整有效transition交给SB3收集器，按设定频率更新
  周期检查点或退出：停车确认 -> 原子保存模型和Replay Buffer
  终止或截断：停车，记录回合结果，再冷reset
发生基础设施错误：停车尝试、销毁所属后端，记录原因；本步不入回放
```

真实后端实现前，`--backend gazebo`持续保持拒绝启动。先验收单场景单worker，再增加课程和并行采样，不提前构造无同步保证的训练循环。

## 评价与迁移

课程顺序：开阔到点、绕障/通道、墙角倒车恢复。按地图布局划分训练、验证和测试，固定评价seed与确定性动作，评价回合不更新模型或回放。每阶段记录到点率、超时率、真值路径长度、用时、停滞时长和基础设施失败数；没有contact数据时碰撞率标unknown。课程升级阈值待先导实验决定，不能凭短测指定“已达标”。

迁移携带源码commit、配置哈希、观测版本、依赖版本和可信检查点；不要拷贝正在写入的回放目录。恢复从新回合开始，CPU/GPU设备切换后重新做动作一致性与短测；不承诺跨硬件逐位一致。模型、Replay Buffer及训练长日志不进入普通Git。
