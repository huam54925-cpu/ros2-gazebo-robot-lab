# AI 连续扫描与移动实验（2026-10-06）

## 本轮行为

用户将实验目标改为直接检验 AI 连续操作能力。当前流程在出生点完成 360° 扫描，向 AI 提供在线地图、位姿、各方向雷达量程和近期动作。AI 可指定任意地图坐标系方向；执行器转向后，按当前扫描中对应方向有效量程的一半直行，再自动进行下一次完整扫描。24 个方向摘要只方便阅读，不限制模型输出方向。

直行目标速度 0.6 m/s，旋转目标速度 0.8 rad/s，终点附近减速。距离按实际对应激光束计算；无回波按传感器最大量程处理，因此半量程不是完整车体通行保证。

本模式不启动传统探索、Nav2 或 velocity guard，命令直接进入 Gazebo 速度话题，不执行地图、车体扫掠与碰撞拒绝。Gazebo 的物理碰撞仍然存在。进程只接受 Docker 中显式启用的实验环境，保存整场期限和停止入口。默认启动配置仍保留此前保护模式。

## 连续性和停止条件

本次连续窗口为 1800 墙钟秒。动作完成后不会退出任务或重置场景。控制代码启动时计算 SHA-256，运行期间不修改。日志持续写入；不以单步低地图收益退出。预算结束、用户停止、模型明确结束或执行/接口故障可结束整场；物理卡住没有自动脱困保障，可能用完整个剩余预算。

## 启动

先结束旧探索进程，确保没有旧 Nav2 或其他速度发布者，再启动全新场景：

```bash
ROBOT_DIRECT_GAZEBO=true ROBOT_HEADLESS=true docker/start-navigation-base.sh mapping
# 另一个终端启动 SLAM
 docker/start-slam.sh
# SLAM 激活后运行；同一时间只启动一个探索实例
scripts/robot-scan-drive.sh --wall-budget 1800 --output /absolute/path/run.json
```

运行目录位于 `workspace/log/scan-drive-<UTC>-<id>/`，保存配置、每次请求、轨迹、结果、地图 PNG/NPZ。总报告保存 AI 参数、用量、耗时、动作结果和冻结源文件哈希。需要用户停止时，在当前运行目录创建 `STOP` 文件；执行器在控制循环中检测。整场结束发送零速度并记录停车反馈。

MCP 只提供 `scan_surroundings`、`drive_half_visible_range` 和 `stop_exploration`。扫描循环由编排器自动推进，AI 每轮直接提交方向；不经过原候选生成或调查任务审批。
