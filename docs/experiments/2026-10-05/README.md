## 昨天两步时间回放

原公式为 `路径长度 / 0.15 + 累积绝对转角 / 0.20 + 4`，单位为仿真秒。`navigation_prediction` 从实时位姿连接到规划器栅格起点，第一小段可能朝后。安全扫掠保留这段很合理，但把它当作实际控制器会执行的两次大转向，会严重高估耗时。

| 指标 | 第一步 | 第二步 |
|---|---:|---:|
| 原估计 / s | 54.913 | 67.227 |
| 实际 before→after 仿真窗口 / s | 26.723 | 32.729 |
| 同一窗口墙钟 / s | 114.415 | 150.560 |
| 完整决策轮墙钟 / s | 188.714 | 252.478 |
| 模型请求墙钟 / s | 8.797 | 11.866 |
| 第一段反向栅格连接 / m | 0.03786 | 0.01194 |
| 原累积转角 / rad | 7.426 | 9.660 |
| 仅估时修正后的转角 / rad | 3.148 | 3.658 |
| 单独修正转角、其余保持旧公式 / s | 33.520 | 37.220 |
| 新暂定期望耗时 / s | 36.520 | 40.220 |
| 带余量的动作预算 / s | 39.520 | 43.542 |

去掉虚假转向解释约 21.393 / 30.007 秒差异。实际轨迹中转弯与平移可以同时发生，导航也不必精确走到每个栅格中心；因此仍保留低速假设，没有用两个样本拟合通用速度或把全部估计统一乘 0.5。

新估计仅用于 **memory** 模式：平移仍按 0.15 m/s，转向仍按 0.20 rad/s，规划/复核暂留 2 s、停车留 1 s、反馈留 4 s，再加 `max(3 s, 运动项的 10%)` 余量。这些开销和余量是显式暂定值，不是历史日志精确测量出的上界。只忽略小于一格对角线且相对下一段反向的起点连接；真实较长回头、路径弯角和终点旋转全部保留。**用于净空和车体扫掠的路径完全不变。**

历史轨迹稀疏采样可回算：第一步平移约 11.200 s、原地转向 7.036 s；第二步约 10.561 / 10.824 s。它们是按左端采样速度分类的局部导航区间，不是精确阶段计时。历史日志没有规划结束、停车开始、模型等待期间仿真时钟的完整边界，相关精确值保持 `null`。反馈墙钟为 15.160 / 17.779 s；仿真速度明显低于实时，不能与仿真秒混用。

最后六个候选重新估时后，最短期望值 37.604 s，加余量为 **40.665 s**，仍高于剩余 **39.999 s**。因此不能声称修正后必然能多走一步；模型等待还会消耗预算。新循环在模型返回后重新读取时钟，动作已放不下就不派发。

## 新增诊断与 Frontier 身份

- 分别记录候选可见首未知边界总格数、相对当前位姿的新增格数、新颖比例；零分母比例为 `null`。它们是同一地图上的射线代理，不是实测动作收益。已有全图 Frontier 格数、簇数、姿态筛选和路径拒绝原因继续保留。
- 预算筛选也逐个记录候选 ID 和距离/时间拒绝原因。模型选择理由、本地执行终态与真实地图窗口均保存。
- 以世界坐标的边界点集在同一 mission/map epoch 内匹配簇，默认关联距离 0.6 m；最大重叠子簇保留 ID，其余子簇记录新 ID 与父簇；合并保留所有父簇祖先。候选批次 ID 刷新不会清空这份关联，终态事件持久化簇与祖先信息。
- 簇关联是启发式诊断，不证明房间身份、可达性或收益饱和，也不产生整簇禁行。局部低收益观察仍按观察点和有效地图证据处理；失败仍只限制对应姿态或有几何见证的入口。新增视点可以继承历史而保持可选。
- 配准不合格的可比较收益和单位成本收益都保持 `null`；原始交叠面积只作诊断。旧事件库兼容新增可选字段，不重写历史证据。
- 模型只接收 patch 摘要，完整坐标/语义样本仍在本地执行器和归档中。昨天第二轮决策上下文序列化长度由 244,659 字符降至 57,280 字符；这不是新的模型延迟实测值。

三份昨日地图的关联见[身份回放](evidence/frontier-identity-replay.json)。真实地图回放中观察到 continued/new；移动、分裂、合并另有合成几何测试，不能冒称昨日地图发生了全部三种变化。
