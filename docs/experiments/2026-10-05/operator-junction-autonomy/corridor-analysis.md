# 为什么这轮没有继续穿过走廊

本轮可确认的是候选表达、阶段目标与预算判断共同影响了选择，不能解释为模型天生缺乏探索意愿，也不能证明在充足预算下它仍会停止。以下依据来自本轮两次决策上下文和当前实现。

| 环节 | 可复核证据 | 影响或限制 |
|---|---|---|
| 场景表达 | `regions.py` 使用 `floor(x/4), floor(y/4)` 的 4 m 网格，模型收到候选和结构化摘要 | 分区不等于走廊、门口或房间；没有显式入口—另一侧关系 |
| 通行价值 | 两轮所有已提供的中转候选，`incremental_boundary_cells=0` | 当前中转点的即时未知边界代理为零；远端潜力与到另一侧的阶段价值需要分开表达 |
| 第一轮选择 | 两个中转候选可执行；模型选择右侧，引用更高面积代理 | 它会行动，但未将用户辅助抵达左侧中转点视为必须继续穿越该入口的目标；交接后实验有意保持自主选点 |
| 连续目标 | 第一轮目标 `R_3_1`；第二轮该方向的 6 个中转姿态均被 `unsafe_pose` 拒绝，当前只提供 `R_0_2` | `committed_region_id` 为 null；可选目标消失后，当前承诺机制没有保留寻找同一入口其他通路的阶段任务 |
| 第二轮停车 | 下一段 5.495 m / 79.42 仿真秒可容纳；剩余 14.887 m / 479.664 仿真秒；远端完整路线 22.407 m | 模型主动按整条远端路线的距离超预算选择 STOP；不是局部动作被预算门或实时 guard 拒绝 |
| 搜索完整性 | 两轮均 `search_complete=false`、`more_candidates=true`；第二轮送检 5 个，短名单 9 个 | “只有一个提供给模型的合格候选”不代表所有安全路径已查尽；当前可在采样未完成时模型停车 |

20 m 总里程预算是本次实验设置，不是环境通行上限。当前提示词已经鼓励接受低即时收益中转、向未知分区扩展，因此仅增加一句“更积极探索”不能保证修复上述机制。

建议的下一步（尚未实施）：

1. 从当前局部地图提取可通行入口，记录入口两侧与待观察方向；不使用预先完整地图或模拟器世界真值。
2. 建立“接近入口 → 穿越 → 另一侧观察”的持续阶段目标；候选 ID 更新后仍保留该目标，安全失效时重新找相应入口的替代路径。
3. 区分本步可执行预算和完整远端路线预算，明确允许预算内的有目的中转及安全停车，不把远端未必本轮完成直接当作停止条件。
4. 模型选择停车而候选搜索未完成时，先补查有界数量的替代候选，再记录最终停止依据。
5. 用单独的通道案例检验通行、另一侧观测、合法返回与无收益往返；配准无效的收益保持 `null`。
