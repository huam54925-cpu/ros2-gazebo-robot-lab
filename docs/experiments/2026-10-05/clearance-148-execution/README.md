## 如何解读这次停止

保存了触发中止的精确地图、路径和姿态。离线回放得到同一预测值，误差 **0.0 m**。同一地图在检查时机器人当前姿态下的净空为 **2.764487 m**；1.420277 m 来自预测路径上的另一个朝向。最差位置离检查时车体位置约 **4.3 cm**，但还需要转约 **157.5°** 才是该假设朝向。

因此，当前实测雷达 2.67 m 与预测路径 1.42 m 并非同一姿态的比较，不能仅据两者差异判定误报。下一步应核对起点栅格连接和姿态扫掠是否要求了实际控制器不会经过的朝向，并区分地图/定位更新影响；这次结果不支持直接宣称车体检查错误或导航成功。

地图由本次实验雷达继续积累，没有重置、加载旧全图或使用世界真值。窗口已知面积从 346.477510 增至 352.432511 m²；栅格配准有效，但没有 accepted-scan 证据，且任务中止。这不是完成目标后的探索收益，也不是整屋覆盖率。
